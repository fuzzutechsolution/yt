Privacy Protection Guide

Follow these essential offline checklists to protect your personal information and active nodes.

01

Enable 2FA (Two-Factor Authentication)

Double the protective shield on accounts by requiring a second verification factor alongside the password.

  • Avoid SMS-based 2FA (susceptible to SIM swap hacks).
  • Use authenticator apps like Google Authenticator or Aegis.
  • Save your emergency backup recovery codes in a physical folder.
02

Use a Password Manager

Avoid credentials recycling by keeping unique passwords for every site inside a secure local crypt.

  • Choose highly rated tools like Bitwarden or KeepassXC.
  • Create a strong Master Passcode that you do not write online.
  • Disable standard browser autocompletion tools to prevent leaks.
03

Keep Browser & Software Updated

Prevent remote attackers from using known software exploits by keeping operating systems patched.

  • Enable automatic updates inside Chrome, Firefox, or Brave.
  • Remove inactive browser extensions (lowers vulnerability surfaces).
  • Restart your system weekly to apply kernel security modifications.
04

Avoid Public WiFi Networks

Public hot-spots are prone to Man-in-the-Middle (MitM) attacks where criminals copy your unencrypted data packets.

  • Use cellular hot-spots instead of airport/cafe networks.
  • If public networks are required, run an encrypted VPN connection.
  • Turn off auto-connect settings on mobile devices.
05

Perform Regular Offline Backups

Mitigate ransomware threats by copying files to offline external storage disks regularly.

  • Follow the 3-2-1 rule: 3 backups, 2 media types, 1 offsite.
  • Use external hard disks that remain unplugged when not in use.
  • Encrypt backups with open tools like VeraCrypt.
06

Audit Device Permissions

Reduce silent mobile tracing by pruning applications from accessing location, contacts, and microphone data.

  • Deny apps background tracking permissions.
  • Revoke microphone access for apps that don't record audio.
  • Delete unused profile applications from cellphones.
